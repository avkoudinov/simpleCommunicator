User Help

The forum provides standard features for communication:

  • User registration. Password reminder. Profile editing. Selection of skin, language, and time zone.
  • Favorite topics and messages.
  • Ability to create custom tags and mark messages with them to effectively find these messages later through tag search.
  • Pinning topics for yourself only.
  • Editing your own messages within N minutes — for both registered and anonymous participants within the current session.
  • Ability to change your vote within N minutes.
  • Attachment gallery for reuse. Ability to mark attachments as favorites, which will always stay at the top for quick selection.
  • User ignore list, ignoring messages from anonymous users (all or individual, black or white list), and ignoring uninteresting topics (no notifications for new messages). When a user is ignored, even their quotes in messages from other non-ignored users are hidden. Two ignore modes — strong and weak. In strong ignore, messages and topics are completely excluded from the feed; in weak ignore, the message text is simply hidden but can be revealed.
  • Preferred forums (to display topics with new messages only from selected forums).
  • Profile topics with separation of messages into thematic and comments. Ability to enable showing only thematic messages.
  • Ability to mark messages as 18+ if they contain images or video clips of a sexual and/or shocking nature. In such messages, images are dimmed, and video clips are collapsed, allowing the reader to decide whether to show the image or not.
  • Subscription features:
    • Subscription to new messages in a topic.
    • Subscription to quotes and replies to your own posts.
    • Subscription to quotes and replies to any other post of interest.
    • Subscription to new messages from a specific user or guest.
    • Subscription to word mentions with morphology support.
    • Subscription to notifications about new registered users.
  • Support for private messages. Private messages are implemented as private topics in a special forum. Participants in a private topic can communicate as in a regular forum topic and can leave the private topic, including the topic author.
  • Creating private topics with personal moderation. In such topics, the author can add and remove participants, delete, and edit messages. Invited participants can leave such a topic, while the author cannot. However, the author can delete it (and restore it if necessary). When deleted, access for invited participants is lost.
  • Support for personal mentions of a participant to draw their attention to your message.
  • Creating poll topics. Open polls (where you can see how each participant voted) and polls with delayed publication (where results are visible only after publication) are supported.
  • Creating topics with delayed publication. Until such a topic is published, it is visible only to the author. They can prepare it, edit, and delete messages, and then publish it. A useful feature for trip reports and similar content.
  • Displaying topics with new messages in a virtual forum "Topics with New Messages". Direct jump to the first new message in a topic. Detailed display of the number of new messages in topics and the number of topics with new messages in forums. Color differentiation: previously visited topics with new messages vs. unvisited topics with new messages.
  • New message digest — a virtual topic consisting of new messages (max 5 from each topic with new messages) — a convenient alternative to the classic approach of reading new messages by entering each topic individually.
  • Ability to view your own deleted messages and attachments.
  • Notification and display of events for users — regarding likes received, deleted or moved messages, moderator warnings and blocks, etc. Event filtering. Marker for processed and unprocessed events.
  • Automatic resizing of image width and height to fit the screen and a close-up view function. Image processing before upload — attempting to compress to allowed sizes and rotate to the correct angle.
  • Protection for users against excessively long messages. Long messages are automatically truncated, and a expand button appears.
  • Conversion of audio files to mp3 format supported by the browser's built-in audio player.
  • Enabling the browser's built-in video player for mp4 video files.
  • Embedding external videos as static images with the option to play the video directly on the page or go to the video hosting site. This solution avoids page load delays due to active objects without sacrificing functionality.
  • Embedding animated GIF and WebP images without immediate loading. The first frame is extracted from the animated image, and a play button is drawn on it. Loading and animation start only when clicked. This solution avoids loading delays and browser lag caused by massive animated images.

These features are offered depending on the context, and their usage is intuitive.

Message Formatting

A text editor with BB-code support is used for writing messages. All codes are inserted via toolbar buttons and are intuitive — the content must be wrapped in specific tags to achieve the desired result.

The following features are explained in more detail:

URL Recognition

The forum automatically recognizes URLs and converts them into active links.

Inserting URLs

Code example:

[url]http://www.google.com/[/url]

Result:

http://www.google.com/

Code example:

[url=http://www.google.com/] Google Search Engine[/url]

Result:

Google Search Engine

Non-standard URL Color

If you set a color for text that is a URL, the color will not apply to the underline.

Code example:

[url][color=#ff2060]http://www.google.com/[/color][/url]

Result:

http://www.google.com/

To apply the color to the underline as well, use the underline tag inside the color tag.

Code example:

[url][color=#ff2060][u]http://www.google.com/[/u][/color][/url]

Result:

http://www.google.com/

Inserting Lists

To create lists, write each list item on a new line and wrap the entire block in [list]...[/list] or [nlist]...[/nlist] tags.

Code example:

[list] Line 1 Line 2 Line 3 [/list]

Result:

  • Line 1
  • Line 2
  • Line 3

Inserting Quotes and Spoilers

To create a quote or a spoiler, wrap the construction in [quote]...[/quote], [spoiler]...[/spoiler], or [ai]...[/ai] tags. The author or comment can be specified in the opening tag.

Code example:

[quote=Author Name]Quoted text.[/quote]

Result:

Author Name
Quoted text.

Inserting Personal Mentions

For a personal mention to draw a participant's attention, place their nickname inside @ or % characters, for example, %author% or @author@. A popup list will suggest nicknames that match the written part.

Gallery Image Layout

Attachments or external images can be formatted as a gallery; they will be displayed as small icons that open the full-size image when clicked.

Code example:

[gallery] [img]http://server.com/images/picture1.jpg[/img] [img]http://server.com/images/picture2.jpg[/img] [attachment=12330] [attachment=12331] [/gallery]

Inserting Videos from Video Hosting Sites

The forum supports embedding videos from popular hosting sites like Vimeo, YouTube, Cube, and others. Tags for them are found in the MEDIA sub-menu. You can insert either the full address or the video ID. Timestamps for start time are also supported.

The system recognizes video links and automatically converts them into embedded videos as if they were wrapped in special tags. If you do not want this conversion, wrap the link in [url]...[/url] tags.

Code example:

[youtube]https://www.youtube.com/watch?v=_qwLHlVjRyw[/youtube] [youtube]_qwLHlVjRyw[/youtube] [youtube]https://youtu.be/_qwLHlVjRyw?t=41[/youtube]

Inserting Tables

For a table, write each row, separating column values with a comma. Empty values are allowed. The first row serves as a header. Wrap the entire block in [table]...[/table] tags.

Code example:

[table]Header 1, Header 2, Header 3 Name 1,244.2,... Name 2,123.5,... "Name 3, with comma",121.5,... "Name 4 ""a,b,c"", with comma and quotes",121.5,... [/table]

Result:

Header 1 Header 2 Header 3
Name 1 244.2 ...
Name 2 123.5 ...
Name 3, with comma 121.5 ...
Name 4 "a,b,c", with comma and quotes 121.5 ...

You can use a different character as a separator, for example [table=|]...[/table]. To use a tabulator, use the designation "tab" [table=tab]...[/table].

To "suppress" the display of the table header, use a minus sign "-" in the first row.

Cell merging is supported. To indicate how many cells to merge, place ::[number] after the cell content. If the content is empty, use just ::[number].

[table]Name,Header 1::2,Header 2::2 ,1.1,1.2,2.1,2.2 Pears,1,2,3,4 Apples,1,2,3,4[/table]

Result:

NameHeader 1Header 2
1.11.22.12.2
Pears1234
Apples1234

Search

The forum provides extensive search capabilities:

  • Search for messages with attachments, images, audio/video, links, code examples, or 18+ content.
  • Search in favorites.
  • Search in private messages.
  • Search within a specific topic.
  • Ability to display only messages meeting search criteria within a multi-page topic — only the topic author's messages, only your own messages, only images, only videos, only thematic messages.
  • Ability to display search results as a general virtual topic or show only matching messages for each topic.
  • Search by tags. Users can create tags and mark messages with them.
  • Search in deleted topics and deleted messages (for moderators).

The quick search bar allows initiating a search from your current location. If you are in a specific sub-forum, the search is automatically limited to that sub-forum.

By default, quick search looks in both topic titles and message text. To search only in topic titles, enter a colon ":" before the search criteria.

If you are inside a topic, entering a colon ":" before the search criteria limits the search to that topic only.

In the advanced search mask, you can also limit the search to a single topic. To select a topic, start typing its title or ID in the "Topic" field; the system will offer suggestions. Entering a hash symbol "#" followed by a number allows searching by topic ID.

In the advanced search mask, there are additional author search options:

  • The word "Guests" means any guest. This helps find guest messages if you don't remember the specific name.
  • The word "Subscription" means any author whose messages you are subscribed to.
  • A colon ":" before the author name means searching by guest nickname. Useful if an author was a guest, then registered, and you want to find their messages from when they were a guest.

Uploading Smileys

The forum allows uploading any number of smileys. Simply place the files in the folder:

user_data/smiles/

The system will automatically display them in the list. The smiley code is the filename without the extension, e.g., for angry.png it is [:angry].

Setting Smiley Order

By default, smileys are sorted by filename. To change this, create a _sort.cnf file in the folder:

user_data/smiles/_sort.cnf

and list the filenames in the desired order:

smile.png biggrin.png angry.png mad.gif sad.png mellow.png ohmy.png blink.png closedeyes.gif shock.gif cry.gif glare.gif unsure.png

Any smileys not mentioned will be added at the end, sorted by filename.

Defining Short Codes for Smileys

To set short codes for smileys, create a _codes.cnf file in the folder:

user_data/smiles/_codes.cnf

Syntax: short code, comma, filename without extension:

:),smile :(,sad ;),wink :<,angry :D,biggrin :8,blink :O,ohmy :P,blum :Q,smoking :|,mellow

System Parameters Configuration

All system parameters are defined in the following file:

include/config_inc.php
  • DEFAULT_SKIN — the default forum skin.
  • DEFAULT_LANGUAGE — the default forum language.
  • TIME_ZONE — the default time zone.
  • TOPICS_PER_PAGE — number of topics per page.
  • POSTS_PER_PAGE — number of posts per page.
  • ATTACHMENTS_PER_POST — maximum number of attachments per post.
  • NEW_TRACKING_PERIOD — period in days during which new messages are tracked.
  • NEW_CHECK_FREQUENCY — frequency of asynchronous checks for new messages.
  • NEW_CACHE_TTL — period in seconds during which cached information about new messages is considered valid.
  • ALLOW_EDIT_PERIOD — period in minutes during which editing and deleting one's own posts is permitted.
  • ALLOW_MODERATE_PERIOD — period in days during which a topic moderator can delete and edit posts in their assigned topic.
  • KEEP_ONLINE_PERIOD — inactivity period in seconds during which a user is considered online.
  • TIMEOUT — maximum request execution time in milliseconds.
  • SALT_KEY — "salt" for encryption and hash code generation.
  • HOME_DIRECTORY — subdirectory relative to the domain if the forum is not installed in the root directory; if in root, then "/".
  • CANONICAL_DOMAIN — domain for the canonical link. If set, a canonical link for search engines is written in the SEO area.
  • MIN_ALLOWED_READMARKER_AGE — minimum age of guest readmarkers in hours, after which guests can post on the forum if restricted guest mode is enabled. This mode is useful if guests are allowed on the forum and someone is attacking it using guest nicknames.
  • WAIT_TIME_AFTER_ATTACK — see below.
  • MAX_REQUESTS_PER_MINUTE — protection parameter against automated attacks. If more than MAX_REQUESTS_PER_MINUTE requests per minute are received from a given IP address, the IP is blocked for the number of minutes specified in the WAIT_TIME_AFTER_ATTACK parameter.
  • MAX_POSTS_PER_MINUTE — protection parameter against automated attacks. If more than MAX_POSTS_PER_MINUTE posts per minute are received from a given IP address, the IP is blocked for the number of minutes specified in the WAIT_TIME_AFTER_ATTACK parameter.
  • JOB_PER_CRON — this flag should be set to 1 if cron or another scheduler is used to perform periodic tasks for clearing outdated data. If hosting does not support cron, tasks are launched once a day after the first user request that occurs within the task launch time interval.
  • BULK_DELETE_COUNT — number of posts deleted per action during batch deletion.
  • MAX_SEARCH_RESULTS — maximum number of search results.
  • GMAPS_API_KEY — API key for Google Maps processing.
  • YOUTUBE_API_KEY — API key for YouTube video processing.
  • VK_CLIENT_SECRET — Client Secret for VKontakte video processing.
  • VK_ACCESS_TOKEN — Access Token for VKontakte video processing.
  • BLOCK_DISPOSABLE_EMAIL_KEY — key for the disposable email address blocking service, see https://www.block-disposable-email.com/cms/.
  • WEB_OPTIMIZED_JPG_SIZE — optimal size for images in kilobytes. The system will attempt to compress images to this size if they exceed it. If an image cannot be compressed to this size, it will still be allowed as long as its final size does not exceed the attachment limit.
  • CONVERT_AMR_TO_MP3 — flag to activate conversion of AMR audio files to MP3. Requires the avconv program.
  • CONVERT_AAC_TO_MP3 — flag to activate conversion of AAC audio files to MP3. Requires the avconv program.
  • CONVERT_M4A_TO_MP3 — flag to activate conversion of M4A audio files to MP3. Requires the avconv program.
  • SUPPORT_LATEX — flag to activate LATEX support (mathematical formula language). Requires texlive and dvipng programs.
  • COMPRESS_PNG — flag to activate compression of PNG files. Requires the pngquant program.
  • CONVERT_PNG_TO_JPG — flag to activate conversion of PNG images to JPG if the PNG size exceeds the limit. Requires the imagemagick/convert program.
  • Settings for debugging and tracing.
  • Email sending parameters (SMTP server).
  • Database connection parameters.

Maintenance Mode

For technical maintenance, the forum can be put into maintenance mode, and visitors will be shown a corresponding message. To do this, in the following file:

include/maintenance_inc.php

enter the estimated end time of the technical maintenance in the format 2017-07-30 15:46:

$maintenance_until = "2017-07-30 15:46";

The end time is purely informative and is not the time when maintenance mode is automatically disabled. To disable maintenance mode, replace the end time with an empty string.

Additionally, you can add a detailed comment (general or for each supported language) about what specific work is being performed.

$maintenance_comment = "Partitioning of the post table is being carried out.";
$maintenance_comment_lang["ru"] = "Проводится партиционирование таблицы постов.";
$maintenance_comment_lang["en"] = "Partitioning of the post table.";
$maintenance_comment_lang["de"] = "Partitionierung der Post-Tabelle.";

As well as a link for more detailed information.

$maintenance_link = "https://www.google.com/";
$maintenance_link_lang["ru"] = "https://www.google.ru/";
$maintenance_link_lang["ua"] = "https://www.google.ru/";
$maintenance_link_lang["en"] = "https://www.google.com/";
$maintenance_link_lang["de"] = "https://www.google.de/";

You can also set a preliminary notification for users that the forum will soon be put into maintenance mode, which is shown once per session. To do this, enter the estimated start and end times of the technical maintenance in the format 2017-07-30 15:46:

$maintenance_start = "2017-07-30 15:46";
$maintenance_end = "2017-07-30 17:46";

To disable the preliminary notification, replace the start and end times with an empty string.

Additionally, you can set a temporary password for debugging:

$adm_debug_password = "passwd";

By entering it in the GET parameter 'admdebug':

forums.php?admdebug=passwd

maintenance mode will be inactive for the current session, and the administrator will be able to test and debug the forum during maintenance, while other visitors see the technical maintenance message.

Furthermore, you can inform users about reduced forum performance during backup periods. The message is shown once per session. For this, a list of weekdays when backups occur and the estimated start and end times of the work are set in the format 01:00.

$backup_days = array(7);
$backup_start = "01:00";
$backup_end = "07:00";
