Technical Information and System Requirements

The forum can be installed on almost any hosting. The forum software has minimal requirements for server configuration and application software settings.

  • Runs on PHP version 8.x or higher.
  • Supports database management systems:
    • MySQL 8.0.x or higher,
    • Microsoft SQL Server 2005 or higher.
  • Works in browsers:
    • Edge;
    • Firefox;
    • Safari;
    • Chrome;
    • Opera.

Advantages

The forum is simple to implement and easy to use.

Skins, time zones, and different interface languages are supported, including for guests.

Skins adapt to the device — desktop or mobile device.

The forum interface is intuitive and does not require studying documentation.

The forum functionality is not overloaded, yet it supports all the main features expected by users from a forum.

AJAX background data transmission technology is used for many actions, ensuring high speed and avoiding unnecessary page refreshes.

Key points of the user-friendly interface are:

  • Accessibility and visibility of options for performing necessary commands depending on the context.
  • Speed of command execution.
  • Use of "light" elements and functions — lightboxes, asynchronous sending.
  • Support for standard intuitive commands and hotkeys — Ctrl + Enter, Ctrl + ←, Ctrl + →, Escape, Tab, etc.
  • "Smart" focusing, eliminating the need for excessive movements and mouse clicks.
  • "Remembering" and automatic restoration of locations, eliminating the need for repeated navigation to the required place.
  • Convenient transition mechanism after sending a message — on previous pages, a transition is made to the next message after the one being replied to, allowing the user to read, send messages, and continue reading. If a message is sent on the last page of a topic, new messages are loaded if they exist.
  • When moving between topic pages, an unsent message is not lost but migrates to the new page, where you can continue quoting and replying to messages.
  • Auto-rotation of images based on EXIF information and compression to a web-optimized size.

A user may not always clearly realize and articulate their criteria and wishes, but it is the above-mentioned nuances that create a positive sense of comfort and convenience when working with the application.

Interface languages supported are Russian, English, German, and Ukrainian. It is easy to add translations for other languages.

The forum features high performance because the number of messages and topics is set during their creation, and there is no need to use resource-intensive aggregation functions when displaying lists of topics and messages. Recalculation of the quantity is only necessary in case of non-standard operations, such as deleting or moving topics and messages.

Load balancing is supported by splitting the database into a master scheme for writing and slave1...slaveN for reading and searching.

Key Features

  • Support for likes and dislikes.
  • Private messages and private group topics with moderation.
  • Log of personal events for users.
  • Log of moderator actions.
  • Statistics for users and forums.
  • Display of users, guests, and bots who have read a topic, subforum, or are simply on the site. Clicking on a bot's name shows its profile and the last topics it visited.
  • Grouping topics with new messages — by subforum, own, with own participation, topics from the favorites list.
  • Digest of new messages.
  • Ability to display found messages as a common virtual topic or show only messages meeting the search criteria for each topic.

Flexible General Settings

  • Enable/disable requirement for account approval by an administrator.
  • Enable/disable display of online status of participants and the topics they visited.
  • Enable/disable rating; you can enable only likes, or make dislikes anonymous.
  • Configure various restrictions — on attachment size, number of topics per day, number of messages per minute, etc.
  • Protection of regular guests' nicknames from theft through registration.
  • Protection against registration of fake and spam accounts via temporary email addresses.
  • Moderator log maintenance. Ability to configure the visibility level of the moderator log — only for administrators, only for moderators, for everyone, or for everyone but without showing moderators' names.
  • Customizable list of emojis and character combinations for inserting them. Ability to categorize emojis.
  • Enable holiday or mourning mode. An indicator image appears; clicking it shows either holiday pictures or a photograph of a deceased participant.
  • Ability to put the forum into maintenance mode with an estimated completion time, as well as notify visitors in advance of planned maintenance with estimated start and end times.

Flexible Settings for Individual Forums

  • Support for closed forums, with access only for specific participants or only for registered participants.
  • Support for closed forums protected by a password.
  • Ability to link the right to post messages on the forum to the age of the nickname (meaning the age of the nickname since registration on the forum) and the number of messages.
  • Ability to ban guests on the forum.
  • Ability to enable limited mode for guests, where only guests with a token age of more than N hours or those whose IP address is on the whitelist can post.
  • Ability to prohibit or allow authors to edit their own messages.
  • Ability to mark a forum as a forum with stricter special rules so that participants are given a warning when writing messages.

Functional Capabilities for Administrators

  • Assignment of forum moderators.
  • Ability to manually activate or approve the account of a registered user.
  • Ability to delete a registered user's account.
  • Ability to make a user privileged, exempting them from restrictions.
  • Ability to make a user a privileged topic moderator, exempting them from topic moderation restrictions.
  • Ability to prohibit a user from sending private messages.
  • Ability to prohibit a forum moderator from performing global moderation operations — global ban, hiding participant profiles, prohibiting rating.
  • Ability to prohibit a forum moderator from seeing IP addresses and fingerprints of participants.
  • Ability to delete a guest's token (read marker) if they waited out the time and logged out to continue violations while limited mode for guests is enabled.
  • Ability to manage a whitelist of IP addresses exempt from limited mode for guests.
  • Ability to manage the list of TOR browser IP addresses — block all or block/allow individual ones for writing or reading.
  • Banning a participant due to death or loss of nickname — in this case, logging into the account is prohibited, not just posting messages from it.

Functional Capabilities for Forum Moderators

  • Quick selection of topics for closing, deleting, merging, and moving to another forum.
  • Quick selection of messages for deletion and moving to another or a new topic.
  • Pinning topics and messages to the header, closing and opening topics.
  • Ability to delete all messages of a selected user or guest with one click in a topic, forum, all forums, or the last N in a forum.
  • Ability to delete a guest's avatar.
  • Ability to view and restore deleted messages, attachments, topics, and forums.
  • Effective flood removal using a special tool that allows deleting messages on the forum for a certain period for all guests or participants by account age.
  • Temporary bans with automatic unban.
  • Ability to ban users only in a specific forum or a specific topic.
  • Ability to assign a user as a moderator of a specific topic in a controlled forum.
  • Ability to grant and revoke access to a controlled closed forum for a user.
  • Ability to hide a user profile (if global moderation operations are permitted).
  • Ability to prohibit a user from rating (if global moderation operations are permitted).
  • Ability to batch delete a user's ratings in a controlled forum.
  • Blocking IP addresses and fingerprints, including temporary blocking with automatic unban (if permission to see IP addresses is granted).

Functional Capabilities for Topic Moderators

  • Quick selection of messages for deletion and moving to another or a new topic.
  • Pinning messages to the header.
  • Ability to delete all messages of a selected user or guest with one click in a topic.
  • Ability to view and restore deleted messages and attachments.
  • Ability to ban users only in the topic.
  • Ability to prohibit or allow guests in the topic.

Functional Capabilities for Users

  • Favorite topics and messages.
  • Ability to create own tags and mark messages with them to effectively find these messages later through tag search.
  • Pinning topics only for oneself.
  • Editing own messages within N minutes — for both registered participants and anonymous participants within the current session.
  • Ability to re-vote within N minutes.
  • Gallery of attachments for reuse. Ability to mark attachments as favorites to always keep them at the top for quick selection.
  • User ignore list, ignoring messages from anonymous users (all or individual, black or white list), and ignoring uninteresting topics (notifications about new messages are not sent for them). When participants are ignored, even their quotes in messages of other non-ignored users are hidden. Two ignore modes — strong and weak. In strong ignore, messages and topics are completely excluded from the feed; in weak ignore, message text is simply hidden but can be shown.
  • Preferred forums (to display topics with new messages only from these forums).
  • Profile topics with separation of messages into thematic ones and comments. Ability to show only thematic messages.
  • Ability to mark messages as 18+ if they contain images or video clips of a sexual and/or shocking nature. In such messages, images are dimmed and video clips are collapsed, allowing the reader to decide whether to show the image or not.
  • Broad subscription options:
    • Subscription to new messages in a topic.
    • Subscription to quotes and replies to your own posts.
    • Subscription to quotes and replies to any other post of interest.
    • Subscription to new messages from a user or guest.
    • Subscription to mentions of words considering morphology.
    • Subscription to notifications about new registered users.
  • Support for private messages. Private messages are implemented as private topics in a special forum. Participants in a private topic can communicate like in a regular forum topic and can leave the private topic, including the author.
  • Creation of private topics with own moderation. In such topics, the author can add and remove participants, delete and edit messages. Invited participants can leave such a topic, while the author cannot. However, they can delete it (and restore it if necessary). Upon deletion, access to the topic for invited participants disappears.
  • Support for personal mentions of a participant to draw their attention to your message.
  • Creation of poll topics. Open polls (where you can see how each participant voted) and polls with delayed publication (where results are visible only after publication) are supported.
  • Creation of topics with delayed publication. Until such a topic is published, it is visible only to the author. They can prepare it, edit and delete messages, and then publish it. A useful feature for trip report topics, etc.
  • Display of topics with new messages in a virtual forum "Topics with new messages". Direct transition to the first new message in a topic. Detailed display of the number of new messages in topics and the number of topics with new messages in forums. Color differentiation of topics: previously visited topics with new messages and never-before-visited topics with new messages.
  • Digest of new messages — a virtual topic made of new messages, max 5 from each topic with new messages — a convenient alternative to the classic approach of reading new messages by entering each topic.
  • Ability to view your own deleted messages and attachments.
  • Notification and display of events for users — about likes received, deleted or moved messages, warnings and blocks by a moderator, etc. Event filtering. Marker for processed and unprocessed events.
  • Automatic reduction of image width and height to screen size and zoom-in function. Image processing before upload — attempting to compress to acceptable sizes and rotate to the correct angle if incorrect.
  • Protection of users from overly long messages. A long message is automatically trimmed, and an expand button appears.
  • Conversion of audio files to mp3 format supported by built-in browser audio players.
  • Enabling the built-in browser video player for mp4 video files.
  • Insertion of external videos as static images with the ability to play the video either directly on the page or go to the video hosting page. This solution eliminates page loading delays due to inserted active objects without compromising functionality.
  • Insertion of animated gif and webp images without immediate loading. The first frame is extracted from the animated image, and a start button is drawn on it. Loading and animation begin only when clicked. This solution eliminates loading delays and browser hangs due to inserted massive animated images.

Statistics for Users

  • Display of various statistical information in the user profile — registration date, last activity, number of messages, likes, dislikes, average number of messages and views per day based on the week, time online per day, and total time online.
  • Contextual options for finding a user's latest messages, topics, attachments, as well as topics moderated and ignored by them.
  • Contextual options for viewing the moderator log and moderating the user.
  • Display of recently read topics.
  • User activity (views and messages) for a specific period.
  • User activity (views and messages) by hour according to the time zone of either the viewed user or the viewing user.
  • Information about ignoring and profile hiding — who ignores the user, whom the user ignores, who hides their profile, whose profile they hide.
  • Viewing rating statistics — who liked/disliked the author, whom the author liked/disliked, user messages with likes/dislikes from other users, users' messages with likes/dislikes from this user, this user's messages with likes/dislikes from other users. Clicking on ratings triggers a selection of messages with those ratings.
  • Analytics for moderators by IP addresses to identify clones. Displaying a list of IP addresses used by this participant to post messages. Showing participants who posted messages under a given IP address. Showing participants who posted messages under the same IP addresses as this participant.

Statistics for Forums

  • New registered users.
  • Number of users who visited the forum (were online).
  • Number of messages posted.
  • Number of topics created.
  • Number of views.
  • Average number of messages per day.
  • Number of ratings given. Clicking on ratings triggers a selection of messages with those ratings.
  • Activity (views and messages).
  • Geography of visits and current activity.
  • Statistics on browsers, operating systems, and bots. Clicking on a bot's name shows its profile and the last topics it visited.

Powerful and Flexible Search

  • User search. Sorting users by rating, number of messages, and activity.
  • Search for messages with attachments, images, audio and video, links, code examples, 18+ content.
  • Search in favorite topics and messages.
  • Search in private messages.
  • Search in a specific topic.
  • Ability to display only messages meeting the search criteria within a multi-page topic — only messages from the topic author, only own messages in the topic, only images, only videos, only thematic ones.
  • Ability to display found messages as a common virtual topic or show only messages meeting the search criteria for each topic.
  • Search by tags. A user can create tags and mark messages with them.
  • Search in deleted topics and deleted messages (for moderators).
